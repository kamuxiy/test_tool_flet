# 2026-08-17 卡顿检测页与打包顺序修复

## 新增「卡顿检测」页

在「流畅性分析」之后、「添加测试机测试壁纸」之前，新增第 7 个 tab「卡顿检测」。

### 页面组成

三个按钮，命令对应项目目录下三个同名 `.bat` 文件：

| 按钮 | 图标 | 执行命令 |
|------|------|----------|
| 开启卡顿检测开关 | 电源开 | `wait-for-device → remount → setprop jankalertenabled true → reboot → wait-for-device → getprop → logcat -d | findstr JankAlertManager` |
| 重启手机并查看丢帧检测是否Ready | 刷新 | `reboot → wait-for-device → ps -ef | findstr com.oplus.midas → logcat -d | findstr JankAlertManager` |
| 关闭卡顿检测开关 | 电源关 | 同开启，`jankalertenabled false` |

### 实现（`main.py`）

- `_HOME_TAB_META` 增加 `("卡顿检测", ft.Icons.MONITOR_HEART_OUTLINED)`
- 新增命令生成函数：
  - `_jank_on_cmds(sn: str)`
  - `_jank_check_cmds(sn: str)`
  - `_jank_off_cmds(sn: str)`
- 新增 `jank_panel`，插入 `_tab_bodies` 中 `perfetto_panel` 之后
- 按钮复用 `acmd()` / `run_chain_ui()`，结果进入右侧运行结果区

### 关键决策

- 命令统一带 `-s {sn}` 前缀，适配顶部下拉框选中的设备
- `logcat` 用 `-d`（dump 后退出）替代 bat 中的流式 `logcat`，避免按钮执行后持续占用进程
- bat 中注释掉的 APK 安装、包路径、kill 命令未加入 UI（用户要求按钮对应操作与结果输出）

## 修复：打包脚本顺序 bug

### 问题
`flet pack` 会清理 `build` 与 `dist\perfetto_worker` 部分内容，导致"先打包 worker、后打包主程序"的顺序会让 worker 丢失。

### 修复（`打包为exe.bat`）
调整顺序为：

1. 先 `flet pack` 打包主程序
2. 再准备精简版 `build\perf_all_in_one_lite`
3. 再 PyInstaller 打包 worker
4. 最后复制 worker 到 `dist\test_tool_flet\perfetto_worker`
